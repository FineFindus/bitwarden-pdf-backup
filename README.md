# Bitwarden PDF Backup

A [typst](https://typst.app) document to back up a Bitwarden vault as a PDF.

1. Export your vault as a `.json` file
2. Rename the export to `bitwarden_export.json`
3. Run `typst compile bitwarden-pdf.typ`


## Why?

A PDF backup can be useful in cases, where the online vault/digital backups are not available.
